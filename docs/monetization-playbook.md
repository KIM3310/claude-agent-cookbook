# Monetization Playbook - claude-agent-cookbook

This is a commercial planning artifact, not a revenue guarantee. It exists to turn an archived technical proof into a clear, ethical selling motion.

## Commercial Lane

- **Lane:** Claude agent implementation enablement
- **Primary buyer:** AI platform teams, product engineering leads, developer education teams, and model platform partners.
- **Why this can sell:** Teams adopting Claude need runnable examples, eval habits, and reusable implementation patterns.

## Offer Ladder

1. **Agent recipe workshop** - $3k-$12k. Walk a team through tool use, RAG, vision, streaming, and eval recipes.
2. **Implementation accelerator** - $20k-$75k. Port selected recipes into a customer's internal architecture.
3. **Developer education bundle** - $2k-$10k/month. License curated recipes, updates, office hours, and internal training material.

## Acquisition Channels

- Claude migration articles
- Developer community demos
- Partner-led enablement sessions

## Proof Gates Before Selling

- Recipes run with mocked tests
- Cost and API-key boundaries are documented
- Stage-pilot relationship is linked

## Risk Boundaries

- Do not imply official vendor ownership
- Keep API pricing and model notes date-stamped when referenced
- Separate educational code from production support commitments

## 30/60/90 Day GTM

- **30 days:** Create a top-three recipe demo route
- **60 days:** Publish an internal-training syllabus
- **90 days:** Bundle recipes into a paid enablement package

## Metrics That Matter

- Workshop bookings
- Recipe completion rate
- Migration leads
- Support hours per cohort

## Positioning Note

Keep the repository's archived status visible. Sell the reusable workflow, diagnostic, enablement material, or pilot path that the proof makes credible; do not sell the archive as an unsupported production service.
