# Revenue Growth Model - claude-agent-cookbook

Updated: 2026-05-30

This note translates the archived proof into a current, ethical revenue path. It keeps the repository's archived status visible while preserving the commercial idea behind the work.

## Model

| Field | Decision |
|---|---|
| Revenue type | Archived proof to diagnostic, workshop, enablement, pilot, or partner package |
| Primary reader or buyer | AI platform teams, product engineering leads, developer education teams, and model platform partners. |
| Wedge | Teams adopting Claude need runnable examples, eval habits, and reusable implementation patterns. |
| Operating note | Sell the revived workflow or advisory package; do not sell an unsupported archive as a live product. |

## Offer Ladder

| Offer | Price assumption | Scope |
|---|---|---|
| Agent recipe workshop | $3k-$12k | Walk a team through tool use, RAG, vision, streaming, and eval recipes. |
| Implementation accelerator | $20k-$75k | Port selected recipes into a customer's internal architecture. |
| Developer education bundle | $2k-$10k/month | License curated recipes, updates, office hours, and internal training material. |

## Activation Loop

- Traffic source: Claude migration articles.
- First action: read the README status note and one proof path that can be checked quickly.
- Conversion offer: Agent recipe workshop.
- Expansion: convert a diagnostic or workshop into a scoped pilot, enablement pack, or maintained partner asset.

## Growth Experiments

- Create a top-three recipe demo route
- Publish an internal-training syllabus
- Bundle recipes into a paid enablement package

## Metrics

- Workshop bookings
- Recipe completion rate
- Migration leads
- Support hours per cohort

## Ethical Boundary

- Do not imply official vendor ownership
- Keep API pricing and model notes date-stamped when referenced
- Separate educational code from production support commitments
- Keep archived status visible in sales or portfolio conversations.
- Do not invent users, revenue, endorsements, certifications, or customer traction.
- Use buyer psychology only to reduce confusion and risk, not to pressure users.
